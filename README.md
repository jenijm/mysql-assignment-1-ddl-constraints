
# MySQL Assignment 1 – DDL Commands & Constraints

## Project Overview
This assignment demonstrates database creation,
table modification, renaming, truncation, dropping,
and the use of SQL constraints in MySQL.

## Topics Covered
- CREATE DATABASE and CREATE TABLE
- ALTER TABLE
- RENAME TABLE
- TRUNCATE TABLE
- DROP TABLE and DROP DATABASE
- PRIMARY KEY and AUTO_INCREMENT
- NOT NULL and UNIQUE
- CHECK and DEFAULT constraints
- FOREIGN KEY relationships

## Tools Used
- MySQL
- MySQL Workbench

## File
MySQL_Assignment_1_DDL_Constraints.sql

## Learning Outcome
Practised creating and modifying database tables,
enforcing data integrity, and establishing relationships
between departments, locations, and employees.
